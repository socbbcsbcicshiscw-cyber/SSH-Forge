# Simple Calculator — modified build

This directory started as a verbatim copy of
[`hobby-projects-lab/simple-calculator`](https://github.com/hobby-projects-lab/simple-calculator)
v1.0.2 (commit `c3d6355`). Since then a small set of user-facing improvements has been applied
on top of it — the list is in [`MODIFICATIONS.md`](MODIFICATIONS.md).

* Upstream project: https://github.com/hobby-projects-lab/simple-calculator
* Upstream license: GNU General Public License v3.0 — see [`LICENSE`](LICENSE).
  The original copyright notices are kept unchanged, and this derived work stays under GPL-3.0.
* Current version of this build: **1.0.3** (`versionCode` 3)
* Application id is unchanged (`hpl.apps.android.math`), because it is the same application with
  improvements; the APKs published here are signed with a separate CI key, so they cannot
  overwrite (or be overwritten by) upstream builds.
