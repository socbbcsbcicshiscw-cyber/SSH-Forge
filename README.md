## Simple Calculator (APK)

[`simple-calculator/`](simple-calculator) is a verbatim copy of
[hobby-projects-lab/simple-calculator](https://github.com/hobby-projects-lab/simple-calculator)
v1.0.2 (GPL-3.0) — an offline Android calculator with arbitrary precision
and a live unit converter.

**Download the ready APK:**
https://github.com/socbbcsbcicshiscw-cyber/SSH-Forge/releases/download/calculator-v1.0.2/simple_calculator_v1.0.2.apk

It is rebuilt automatically from the unmodified sources by the
[`Calculator APK`](.github/workflows/calculator-apk.yml) workflow, and published on the
[releases page](https://github.com/socbbcsbcicshiscw-cyber/SSH-Forge/releases) together with a
`.sha256` checksum.
