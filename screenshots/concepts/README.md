# Concept visuals only

The six PNGs in this directory are illustrative designs based on the current app source. They are **not screenshots**, were not captured from an Android device/emulator, and do not represent a live SSH connection. Each is prominently labeled and includes a concept-specific disclaimer. No server output, successful session, or real fingerprint is depicted.

See [`../../docs/graphics-inventory.md`](../../docs/graphics-inventory.md) for dimensions and content notes. Do not copy these files into `screenshots/store/` or upload them as store screenshots.
